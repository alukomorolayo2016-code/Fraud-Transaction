Fraud Transaction Dashboard
Overview
The Fraud Transaction Dashboard is an interactive analytics tool designed to monitor, detect, and analyze potentially fraudulent transactions in real-time. This dashboard provides actionable insights to help identify suspicious patterns and prevent financial losses.

The project was developed using Metabase for visualization and SQL for querying and aggregating data from the transactional database.

Features
Real-Time Transaction Monitoring – View the latest transactions as they occur.
Fraud Detection Metrics – Key indicators such as high-risk transactions, unusual transaction frequency, and anomaly detection.
Transaction Filtering & Drill-Down – Filter transactions by date, customer, product line, or location.
Visual Analytics – Interactive charts, graphs, and tables for easy identification of suspicious activity.

Technologies Used
Metabase – For building interactive dashboards and visual analytics.

SQL (PostgreSQL) – For querying, aggregating, and preparing data for visualization.

Database – Transactional database containing historical and live transaction records.
